## 1. Continuous Batching

动态批处理，请求随到随处理：

```
传统 Static Batching:
Batch 1: [Req1────] [Req2────] [Req3────] → 等待全部完成
Batch 2: [Req4────] [Req5────] [Req6────] → 等待全部完成

Continuous Batching:
时间 →  [Req1──]
        [Req2────────]
              [Req3───]  ← Req1 完成后立即加入
                  [Req4──] ← 动态加入
```

## 2. Prefill-Decode 分离

```
问题: Prefill (计算密集) vs Decode (内存密集) 特性不同

解决方案:
┌─────────────────┬─────────────────┐
│ Prefill 批次     │  Decode 批次    │
│ 优化: 大批量      │  优化: 高并发   │
│ GPU 计算密集     │  GPU 内存密集   │
└─────────────────┴─────────────────┘
```

## 3. 量化技术

| 量化类型        | 精度     | 内存节省 | 速度提升 |
| --------------- | -------- | -------- | -------- |
| FP16            | 基准     | 基准     | 基准     |
| FP8             | 轻微损失 | 50%      | 1.5-2x   |
| INT4 (AWQ/GPTQ) | 可接受   | 75%      | 2-3x     |

```bash
# FP8 启动
python -m sglang.launch_server --model meta-llama/Llama-3-8B \
    --quantization fp8

# INT4 启动
python -m sglang.launch_server --model TheBloke/Llama-3-8B-AWQ \
    --quantization awq
```

## 4. Speculative Decoding

使用小模型预测、大模型验证：

```
小模型快速生成: [token1, token2, token3, token4]
大模型验证:     [  ✓   ,   ✓   ,   ✗   ,   -   ]
结果:           [token1, token2] + 大模型重新生成 token3

加速: 2-3x (取决于接受率)
```

## 5. FlashAttention

```
标准 Attention: O(N²) 内存
FlashAttention: O(N) 内存 + IO 优化

启用 (默认开启):
python -m sglang.launch_server --model ... --enable-flashinfer
```

## 启动参数速查

```bash
# 高性能配置
python -m sglang.launch_server \
    --model meta-llama/Llama-3-70B \
    --tp 4 \                        # 4 GPU 张量并行
    --quantization fp8 \            # FP8 量化
    --enable-flashinfer \           # FlashAttention
    --max-total-tokens 65536 \      # 最大 token 数
    --schedule-policy lpm           # 调度策略
```
