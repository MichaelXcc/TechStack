# SGLang 分布式部署

## 并行策略概览

```
┌─────────────────────────────────────────────────────────────┐
│                     分布式并行策略                           │
├─────────────────────────────────────────────────────────────┤
│  张量并行 (TP)     │ 单层切分到多 GPU                        │
│  流水线并行 (PP)   │ 不同层分到不同 GPU                      │
│  数据并行 (DP)     │ 多副本处理不同请求                      │
│  专家并行 (EP)     │ MoE 模型专用                           │
└─────────────────────────────────────────────────────────────┘
```

## 张量并行 (TP)

```bash
# 4 GPU 张量并行
python -m sglang.launch_server \
    --model meta-llama/Llama-3-70B \
    --tp 4

# 计算: 70B 模型需要 ~140GB (FP16)
# 4x A100 80GB = 320GB → 足够
```

## 流水线并行 (PP)

```bash
# 张量并行 + 流水线并行
# 适用于超大模型 (如 405B)
--tp 4 --pp 2  # 8 GPU: 4路TP × 2路PP
```

## 多节点部署

```bash
# 节点 0 (主节点)
python -m sglang.launch_server \
    --model meta-llama/Llama-3-405B \
    --tp 8 --dist-init-addr 10.0.0.1:12345 \
    --nnodes 2 --node-rank 0

# 节点 1
python -m sglang.launch_server \
    --model meta-llama/Llama-3-405B \
    --tp 8 --dist-init-addr 10.0.0.1:12345 \
    --nnodes 2 --node-rank 1
```

## 模型与 GPU 配置参考

| 模型大小   | 推荐配置   | GPU 内存需求 |
| ---------- | ---------- | ------------ |
| 7-8B       | TP=1       | 1x 16GB+     |
| 13B        | TP=1       | 1x 24GB+     |
| 70B        | TP=4       | 4x 40GB+     |
| 70B (量化) | TP=2       | 2x 40GB+     |
| 405B       | TP=8, PP=2 | 16x 80GB     |

## Docker 部署

```bash
docker run -d --gpus all \
    -p 8000:8000 \
    -v ~/.cache/huggingface:/root/.cache/huggingface \
    lmsysorg/sglang:latest \
    python -m sglang.launch_server \
    --model meta-llama/Llama-3-8B \
    --host 0.0.0.0 --port 8000
```
