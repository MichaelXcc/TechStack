# SGLang 实战案例

## 案例 1: 多轮对话服务

```python
import sglang as sgl

@sgl.function
def multi_turn_chat(s, history, new_message):
    s += sgl.system("You are a helpful assistant.")

    for msg in history:
        if msg["role"] == "user":
            s += sgl.user(msg["content"])
        else:
            s += sgl.assistant(msg["content"])

    s += sgl.user(new_message)
    s += sgl.assistant(sgl.gen("response", max_tokens=512))

# RadixAttention 自动复用历史对话的 KV Cache
```

## 案例 2: RAG 检索增强

```python
@sgl.function
def rag_answer(s, documents, question):
    s += sgl.system("Answer based on the documents provided.")
    s += f"\n## Documents:\n{documents}\n"
    s += sgl.user(question)
    s += sgl.assistant(sgl.gen("answer"))

# 多个问题共享相同文档时，文档部分 KV Cache 被复用
```

## 案例 3: 结构化 JSON 输出

```python
@sgl.function
def extract_entities(s, text):
    s += f"Extract entities from: {text}\n"
    s += "Output JSON format:\n"
    s += sgl.gen("entities",
                 regex=r'\{"persons": \[.*\], "locations": \[.*\]\}')

result = extract_entities.run(text="John met Mary in Paris.")
# 输出保证符合 JSON 格式
```

## 案例 4: 批量分类任务

```python
@sgl.function
def classify_sentiment(s, text):
    s += f"Text: {text}\nSentiment:"
    s += sgl.select("sentiment", ["positive", "negative", "neutral"])

# 批量处理
texts = ["Great product!", "Terrible service", "It's okay"]
results = classify_sentiment.run_batch([{"text": t} for t in texts])
```

## 案例 5: 思维链推理

```python
@sgl.function
def chain_of_thought(s, question):
    s += sgl.user(question)
    s += sgl.assistant("Let me think step by step:\n")
    s += sgl.gen("reasoning", max_tokens=500)
    s += "\nTherefore, the answer is: "
    s += sgl.gen("answer", max_tokens=100)
```

## 性能最佳实践

1. **最大化前缀共享**: 公共内容放前面
2. **批量处理**: 使用 `run_batch()` 提高吞吐
3. **合理设置 max_tokens**: 避免浪费
4. **选择合适的量化**: 权衡精度和速度
