# 架构决策记录 (ADR)

## 📖 什么是 ADR

**架构决策记录 (Architecture Decision Record, ADR)** 是一种文档格式，用于记录在软件架构过程中做出的重要决策。

### 为什么需要 ADR

- 📝 **知识保留**: 记录决策背景，避免知识流失
- 🔍 **可追溯性**: 追溯为什么做出某个决策
- 👥 **团队对齐**: 让团队成员理解决策原因
- ⏪ **历史回顾**: 评估过去决策的效果

## 📊 ADR 状态

| 状态                   | 说明               |
| ---------------------- | ------------------ |
| 🟡 提议中 (Proposed)   | 决策正在讨论中     |
| 🟢 已采纳 (Accepted)   | 决策已被接受并实施 |
| 🔴 已废弃 (Deprecated) | 决策已不再适用     |
| ⚫ 已取代 (Superseded) | 已被新决策取代     |
