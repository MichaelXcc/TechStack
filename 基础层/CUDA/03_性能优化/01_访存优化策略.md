# 访存优化策略

CUDA 程序性能的瓶颈通常在于 **内存带宽 (Memory Bound)** 而不是计算能力。优化访存是提升性能的首要任务。

## 1. Global Memory: 合并访问 (Coalescing)

这是最重要的优化点。
- **什么是合并访问**: Warp 内的32个线程访问连续的、对齐的内存地址。
- **目标**: 将多个线程的内存请求合并为尽可能少的内存事务。
- **结构体数组 (AoS) vs 数组结构体 (SoA)**:
    - **AoS (Array of Structures)**: `struct Point { float x, y, z; }; Point p[N];`
        - 线程 `tid` 访问 `p[tid].x`，使得地址间隔为 `sizeof(Point)` (12 bytes)，导致非合并访问。
    - **SoA (Structure of Arrays)**: `struct Points { float *x, *y, *z; };`
        - 线程 `tid` 访问 `x[tid]`，地址连续，实现完美合并。
    - **建议**: 在 GPU 上尽量使用 SoA 布局。

## 2. Shared Memory: 数据分块 (Tiling)

利用 Shared Memory 作为用户管理的 Cache。

### 矩阵乘法 Tiling 示例
如果不使用 Shared Memory，每个线程都需要从 Global Memory 重复读取多次某行或某列的数据。
通过 Tiling：
1.  Block 里的线程协作，将一小块数据 (Tile) 从 Global Memory 加载到 Shared Memory。
2.  同步 `__syncthreads()`。
3.  线程从 Shared Memory 读取数据进行计算 (速度快)。
4.  重复步骤。

### 避免 Bank Conflict
Shared Memory 被划分为 32 个 Bank (4-byte width)。
- **冲突**: 多个线程同时访问同一个 Bank 的不同地址。
- **解决**: 通过填充 (Padding) 改变数据布局，使访问错开。
    - 例如: 声明 `__shared__ float s[32][32]` 可能导致冲突，改为 `s[32][33]` 可错开 Bank。

## 3. 其他存储优化
- **Constant Memory**: 如果所有线程读取相同数据（如卷积核系数），使用 `__constant__` 变量。
- **Read-Only Cache (LDG)**: 使用 `__ldg()` 指令或 `const __restrict__` 指针，利用只读缓存路径。
