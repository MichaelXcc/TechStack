# 指令与计算优化

虽然内存通常是瓶颈，但在计算密集型 (Compute Bound) 任务中，指令优化也很重要。

## 1. 精度与内建函数 (Intrinsic Functions)

- **单精度 vs 双精度**: GPU 的单精度 (float) 吞吐量通常远高于双精度 (double)。如果精度允许，优先使用 `float`。
- **标准函数 vs 内建函数**: 
    - 标准数学函数 (如 `sin`, `exp`, `pow`) 精度高但速度较慢。
    - CUDA 提供了内建函数 (如 `__sinf`, `__expf`)，直接映射到硬件指令，速度极快但精度稍低 (fast math)。
    - 编译选项: `-use_fast_math` 可以让编译器自动将所有数学函数替换为内建版本。

## 2. 循环展开 (Loop Unrolling)

通过展开循环体，减少循环控制指令（比较、跳转、索引更新）的开销，并增加指令级并行度。

```cpp
#pragma unroll
for (int i = 0; i < 100; ++i) {
    // ...
}
```
使用 `#pragma unroll` 提示编译器尝试完全展开或部分展开循环。

## 3. 控制流优化

减少 Warp Divergence（前文已述）。
- 如果条件判断仅依赖于常数或 Block 统一的变量，不会导致发散。
- **Predication (谓词执行)**: 对于短小的分支，编译器可能会使用谓词指令（将条件码写入寄存器，指令按条件执行）代替跳转指令，从而避免流水线冲刷。

## 4. 其它技巧
- **位运算**: 用位移代替整数乘除法（编译器通常会自动优化，但手动写更保险）。
- **FMA (Fused Multiply-Add)**: 使用 `fmaf(a, b, c)` 执行 `a*b+c`，只需一个指令周期且精度更高（只有一次舍入）。
