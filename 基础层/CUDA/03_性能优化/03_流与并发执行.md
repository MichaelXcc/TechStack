# 流与并发执行

为了进一步压榨 GPU 性能，我们需要让 GPU "忙起来"，减少空闲时间。

## 1. CUDA Stream (流)

流 (Stream) 是一系列按顺序执行的 CUDA 操作（Kernel 启动、内存拷贝）的队列。
- **默认流 (Default Stream / Stream 0)**: 如果不指定流，操作都会提交到默认流，串行执行。
- **非默认流**: 可以创建多个流，不同流中的操作可以 **并发执行**（在硬件资源允许的情况下）。

## 2. 重叠计算与传输 (Overlap Data Transfer and Computation)

这是一个经典的优化模式。
在处理大规模数据时，如果一次性将数据全部拷贝到 GPU，然后计算，再拷回，会导致 GPU 在拷贝期间空闲，PCIe 总线在计算期间空闲。

通过将数据切片，使用多个流流水线化执行：

**Stream 1**: [Copy H2D] -> [Kernel] -> [Copy D2H]
**Stream 2**:            [Copy H2D] -> [Kernel] -> [Copy D2H]
**Stream 3**:                       [Copy H2D] -> [Kernel] -> [Copy D2H]

此时，Stream 1 的 Kernel 计算可能与 Stream 2 的内存拷贝同时进行，从而隐藏了传输延迟。

### 关键 API
- `cudaStreamCreate(&stream)`
- `cudaMemcpyAsync(dst, src, count, kind, stream)`: 异步拷贝，必须使用 `cudaMallocHost` (Pinned Memory/页锁定内存) 分配的 Host 内存。
- `kernel<<<grid, block, shared, stream>>>(...)`: 在指定流中启动 Kernel。
- `cudaStreamSynchronize(stream)`: 等待特定流完成。
- `cudaDeviceSynchronize()`: 等待设备上所有流完成。

## 3. 并发 Kernel 执行
在较新的 GPU 上，如果一个 Kernel 占用的 SM 资源较少，可以在不同的流中同时启动多个 Kernel，它们会在 GPU 上并发运行，提高 SM 利用率。
