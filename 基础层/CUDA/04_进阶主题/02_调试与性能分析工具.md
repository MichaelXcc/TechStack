# 调试与性能分析工具

工欲善其事，必先利其器。

## 1. 性能分析 (Profiling)

### Nsight Systems (`nsys`)
- **定位**: **系统级** 性能分析工具。
- **用途**: 查看 CPU 与 GPU 的交互、Timeline、API 调用耗时、显存拷贝耗时。
- **最佳实践**: 优化的第一步。先用它看整体瓶颈在哪里（是卡在 PCIe 传输，还是卡在 Kernel 计算，还是 CPU 调度太慢）。
- **命令**: `nsys profile ./my_app`

### Nsight Compute (`ncu`)
- **定位**: **Kernel 级** 性能分析工具。
- **用途**: 深入分析某个具体 Kernel 的内部行为（指令吞吐、内存带宽利用率、Cache 命中率、Occupancy 分析）。
- **最佳实践**: 当不需要优化整体流程，而是要死磕某个 Kernel 的特定性能时使用。
- **命令**: `ncu ./my_app`

## 2. 调试 (Debugging)

### Compute Sanitizer
- **用途**: 检查内存错误（越界访问、未对齐访问）、竞态条件 (Race Condition)。
- **前身**: `cuda-memcheck` (已弃用)。
- **命令**: `compute-sanitizer ./my_app`

### CUDA-GDB
- **用途**: 命令行调试器，类似于 GDB，可在 Device 代码中设置断点、单步执行。

### Nsight Visual Studio Code Edition
- **用途**: VS Code 插件，提供图形化的调试和代码高亮支持。

## 3. 性能优化工作流
1.  **NsYs** 看全景：确定瓶颈位置。
2.  **Compute Sanitizer** 查错：确保逻辑正确，没有非法访问。
3.  **NCU** 看细节：针对瓶颈 Kernel 进行微观指令级优化。
