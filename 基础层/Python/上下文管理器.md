# Python上下文管理器 (Context Managers)

## 💡 核心概念
上下文管理器用于规定某个对象的使用范围，确保资源在不使用时能被正确释放。最常见的用法是 `with` 语句。
- **协议**：实现 `__enter__` 和 `__exit__` 方法。
- **目的**：自动管理资源的获取和释放（如文件句柄、网络连接、数据库事务、锁）。

## 🔍 主要应用场景
1. **文件操作**：自动关闭文件。
2. **线程锁**：自动获取和释放锁。
3. **数据库事务**：自动提交或回滚。
4. **异常处理**：抑制特定异常。

## 💻 代码示例

### 1. 基于类的实现
```python
class FileManager:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode
        self.file = None

    def __enter__(self):
        self.file = open(self.filename, self.mode)
        return self.file

    def __exit__(self, exc_type, exc_val, exc_tb):
        if self.file:
            self.file.close()
        # 如果返回 True，则吞掉异常；否则异常会继续抛出
        return False 

with FileManager('test.txt', 'w') as f:
    f.write('Hello')
```

### 2. 基于 `contextlib` 的简化实现
使用 `@contextmanager` 装饰器可以将生成器转化为上下文管理器。
```python
from contextlib import contextmanager

@contextmanager
def my_open(filename, mode):
    f = open(filename, mode)
    try:
        yield f
    finally:
        f.close()

with my_open('test.txt', 'w') as f:
    f.write('Hello')
```

### 3. `contextlib.suppress`
用于忽略指定的异常。
```python
from contextlib import suppress
import os

with suppress(FileNotFoundError):
    os.remove('somefile.tmp')
```
