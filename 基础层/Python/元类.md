# Python元类 (Metaclasses)

## 💡 核心概念
元类是"类的类"。在Python中，一切皆对象，类本身也是一个对象，而创建这个类对象的"东西"就是元类。
- **普通对象**是**类**的实例
- **类**是**元类**的实例
- Python中默认的元类是 `type`

> [!NOTE] 核心公式
> `Instance = Class()`
> `Class = Metaclass()`

## 🔍 主要应用场景
1. **拦截类的创建**：在类创建时修改类的定义（自动添加方法、属性检查）。
2. **注册机制**：自动将所有子类注册到某个中心注册表中（常用于插件系统、ORM框架）。
3. **接口检查**：强制子类实现某些特定的方法或属性。

## 💻 代码示例

### 1. 基础语法
```python
class MyMeta(type):
    def __new__(cls, name, bases, attrs):
        print(f"Creating class: {name}")
        # 在这里可以修改 attrs，例如自动转化为大写
        return super().__new__(cls, name, bases, attrs)

class MyClass(metaclass=MyMeta):
    pass
# 输出: Creating class: MyClass
```

### 2. 实战：自动注册插件系统
```python
class PluginRegistry(type):
    plugins = {}
    
    def __init__(cls, name, bases, attrs):
        if name != 'BasePlugin':
            print(f"Registering plugin: {name}")
            PluginRegistry.plugins[name] = cls
        super().__init__(name, bases, attrs)

class BasePlugin(metaclass=PluginRegistry):
    pass

class AudioPlugin(BasePlugin):
    pass

class VideoPlugin(BasePlugin):
    pass

# PluginRegistry.plugins 现在包含了 AudioPlugin 和 VideoPlugin
```

## ⚠️ 注意事项
- **过度设计**：99%的场景下你不需要使用元类。通常简单的继承或类装饰器就能解决问题。
- **复杂性**：元类会增加代码的理解难度，尽量保持逻辑简单。
