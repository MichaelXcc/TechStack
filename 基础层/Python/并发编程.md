# Python并发编程 (Concurrency)

## 💡 核心概念
Python中的并发编程主要涉及三种模式：多线程、多进程和异步IO。理解它们的核心在于理解 **GIL (Global Interpreter Lock)**。

### GIL (全局解释器锁)
CPython解释器中，同一时刻只能有一个线程执行Python字节码。这意味着**多线程无法利用多核CPU**进行并行计算，只能并发执行。

## 🔍 模式选择指南

| 模式 | 库 | 适用场景 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- | :--- |
| **多线程 (Threading)** | `threading` | **IO密集型** (爬虫、文件读写) | 轻量，共享内存方便 | 受GIL限制，CPU密集型无提速 |
| **多进程 (Multiprocessing)** | `multiprocessing` | **CPU密集型** (科学计算、图像处理) | 绕过GIL，利用多核 | 进程间通信开销大，内存占用高 |
| **异步IO (AsyncIO)** | `asyncio` | **高并发IO** (Web服务、大量连接) | 极高的并发量，单线程无锁 | 编程模型复杂(传染性)，生态库支持要求 |

## 💻 代码示例

### 1. 多线程 (IO密集型)
```python
import threading
import time

def io_task():
    time.sleep(1)

threads = [threading.Thread(target=io_task) for _ in range(10)]
for t in threads: t.start()
for t in threads: t.join()
```

### 2. 多进程 (CPU密集型)
```python
from multiprocessing import Pool

def cpu_task(x):
    return x * x

if __name__ == '__main__':
    with Pool(4) as p:
        print(p.map(cpu_task, [1, 2, 3]))
```

### 3. AsyncIO (异步编程)
```python
import asyncio

async def async_task():
    await asyncio.sleep(1)
    print("Task completed")

async def main():
    await asyncio.gather(async_task(), async_task())

# asyncio.run(main()) 
```

## ⚠️ 常见陷阱
- **死锁**：多线程共享资源时必须小心使用锁 (`Lock`)。
- **僵尸进程**：多进程编程时需确保子进程正确回收。
- **阻塞操作**：在 `async` 函数中严禁调用阻塞式IO（如 `time.sleep` 或 `requests.get`），会阻塞整个事件循环。
