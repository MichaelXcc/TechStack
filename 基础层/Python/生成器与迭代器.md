# Python生成器与迭代器 (Generators & Iterators)

## 💡 核心概念

### 迭代器 (Iterator)
- 实现了迭代协议的对象，即包含 `__iter__()` 和 `__next__()` 方法。
- **特点**：惰性求值（Lazy Evaluation），只能遍历一次，节省内存。

### 生成器 (Generator)
- 一种特殊的迭代器，使用 `yield` 关键字的函数。
- **特点**：语法更简洁，自动实现迭代协议，自动保存执行状态。

## 🔍 主要应用场景
1. **处理大数据流**：避免一次性加载大量数据到内存（如读取超大文件、数据库查询结果）。
2. **无限序列**：生成斐波那契数列等。
3. **协程基础**：生成器是Python协程（Coroutine）的前身。

## 💻 代码示例

### 1. 迭代器协议
```python
class CountDown:
    def __init__(self, start):
        self.count = start
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.count <= 0:
            raise StopIteration
        val = self.count
        self.count -= 1
        return val

for x in CountDown(3):
    print(x)  # 3, 2, 1
```

### 2. 生成器函数
```python
def count_down_gen(start):
    while start > 0:
        yield start
        start -= 1

# 使用生成器表达式 (类似列表推导式，但用圆括号)
squares_gen = (x*x for x in range(10))
```

### 3. `yield from` (Python 3.3+)
用于委托给子生成器，简化嵌套生成器的代码。
```python
def chain(*iterables):
    for it in iterables:
        yield from it  # 等价于 for element in it: yield element

list(chain('ABC', range(3)))  # ['A', 'B', 'C', 0, 1, 2]
```

## ⚠️ 性能对比
| 特性 | 列表 (List) | 生成器 (Generator) |
| :--- | :--- | :--- |
| **内存占用** | 高 (存储所有元素) | 低 (仅存储状态) |
| **访问速度** | 快 (支持索引访问) | 慢 (只能顺序访问) |
| **适用场景** | 需要随机访问、数据量小 | 数据量大、流式处理 |
