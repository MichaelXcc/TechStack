# Python类型提示 (Type Hinting)

## 💡 核心概念
Python 3.5+ 引入了类型提示（Type Hints），虽然Python运行时依然是动态类型的（不会强制校验类型），但类型提示极大地改善了代码的可读性和IDE的智能感知能力，并配合静态分析工具（如 `mypy`）提前发现错误。

## 🔍 主要应用场景
1. **大型项目**：提高代码可维护性，充当文档。
2. **API定义**：明确输入输出规范。
3. **静态检查**：CI/CD流水线中集成 `mypy` 检查。

## 💻 代码示例

### 1. 基础类型与集合
```python
from typing import List, Dict, Tuple, Optional, Union

# 变量注解
age: int = 25
scores: List[int] = [80, 90, 100]
user_info: Dict[str, str] = {"name": "Alice"}

# 函数注解
def greet(name: str) -> str:
    return f"Hello, {name}"

# 可选类型 (int 或 None)
def find_user(user_id: int) -> Optional[str]:
    return "Alice" if user_id == 1 else None

# 联合类型 (int 或 float)
def process(number: Union[int, float]) -> float:
    return float(number)
```

### 2. Python 3.9+ 新语法
可以直接使用内置集合类型，无需从 `typing` 导入。
```python
def process_items(items: list[str]) -> dict[str, int]:
    return {item: len(item) for item in items}
```

### 3. 泛型 (Generics)
```python
from typing import TypeVar, Sequence

T = TypeVar('T')

def first_element(seq: Sequence[T]) -> T:
    return seq[0]
```

### 4. 协议 (Protocol) - 鸭子类型
类似于Go的interface，不关心继承关系，只关心是否实现了特定方法。
```python
from typing import Protocol

class Drawable(Protocol):
    def draw(self) -> None: ...

def render(obj: Drawable):
    obj.draw()
```

## 🛠️ 静态检查工具
**Mypy** 是最流行的Python静态类型检查器。
```bash
pip install mypy
mypy program.py
```
