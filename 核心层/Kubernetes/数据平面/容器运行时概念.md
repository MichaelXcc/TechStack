# 容器运行时概念

## 📋 定义

容器运行时是Kubernetes数据平面的核心组件，负责管理容器的生命周期，包括创建、启动、停止和删除容器。

## 🎯 核心特性

### 1. 容器管理
- **容器生命周期**：管理容器的创建、启动、停止、删除
- **镜像管理**：拉取、存储和管理容器镜像
- **资源隔离**：使用cgroups和namespace实现资源隔离

### 2. 标准接口
- **CRI**：容器运行时接口
- **OCI**：开放容器倡议
- **标准化**：提供标准化的容器管理接口

### 3. 高性能
- **轻量级**：高效的容器管理
- **快速启动**：快速创建和启动容器
- **低开销**：最小的资源开销

## 📝 容器运行时类型

### Docker
```yaml
# kubelet配置
--container-runtime=docker
--docker-endpoint=unix:///var/run/docker.sock
--docker-runtime=unix:///var/run/docker.sock
```

**特点**：
- 最流行的容器运行时
- 支持完整的Docker功能
- 丰富的生态系统

**架构**：
```
Kubelet
    ↓
Docker Shim
    ↓
Docker Daemon
    ↓
containerd
    ↓
runc
```

### containerd
```yaml
# kubelet配置
--container-runtime=remote
--container-runtime-endpoint=unix:///run/containerd/containerd.sock
```

**特点**：
- 轻量级容器运行时
- 高性能
- 符合CRI标准

**架构**：
```
Kubelet
    ↓
CRI Plugin
    ↓
containerd
    ↓
runc
```

### CRI-O
```yaml
# kubelet配置
--container-runtime=remote
--container-runtime-endpoint=unix:///var/run/crio/crio.sock
```

**特点**：
- 专为Kubernetes设计
- 轻量级
- 符合CRI和OCI标准

**架构**：
```
Kubelet
    ↓
CRI-O
    ↓
runc
```

## 🔧 CRI接口

### CRI服务
```go
// RuntimeService
type RuntimeService interface {
    // 创建容器
    CreateContainer(ctx context.Context, container *Container) (*CreateContainerResponse, error)
    
    // 启动容器
    StartContainer(ctx context.Context, containerID string) (*StartContainerResponse, error)
    
    // 停止容器
    StopContainer(ctx context.Context, containerID string, timeout int64) (*StopContainerResponse, error)
    
    // 删除容器
    RemoveContainer(ctx context.Context, containerID string) (*RemoveContainerResponse, error)
    
    // 查询容器状态
    ContainerStatus(ctx context.Context, containerID string) (*ContainerStatusResponse, error)
    
    // 列出容器
    ListContainers(ctx context.Context, filter *ContainerFilter) (*ListContainersResponse, error)
}

// ImageService
type ImageService interface {
    // 拉取镜像
    PullImage(ctx context.Context, image *ImageSpec) (*PullImageResponse, error)
    
    // 列出镜像
    ListImages(ctx context.Context, filter *ImageFilter) (*ListImagesResponse, error)
    
    // 删除镜像
    RemoveImage(ctx context.Context, image *ImageSpec) (*RemoveImageResponse, error)
    
    // 查询镜像状态
    ImageStatus(ctx context.Context, image *ImageSpec) (*ImageStatusResponse, error)
}
```

## 🔧 容器运行时配置

### Docker配置
```yaml
# /etc/docker/daemon.json
{
  "exec-opts": ["native.cgroupdriver=systemd"],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m",
    "max-file": "3"
  },
  "storage-driver": "overlay2",
  "storage-opts": [
    "overlay2.override_kernel_check=true"
  ],
  "registry-mirrors": [
    "https://mirror.gcr.io"
  ],
  "insecure-registries": [
    "registry.example.com:5000"
  ]
}
```

### containerd配置
```toml
# /etc/containerd/config.toml
[plugins]
  [plugins."io.containerd.grpc.v1.cri"]
    [plugins."io.containerd.grpc.v1.cri".containerd]
      snapshotter = "overlayfs"
      default_runtime_name = "runc"
    [plugins."io.containerd.grpc.v1.cri".registry]
      [plugins."io.containerd.grpc.v1.cri".registry.mirrors]
        [plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
          endpoint = ["https://mirror.gcr.io"]
    [plugins."io.containerd.grpc.v1.cri".containerd.runtimes]
      [plugins."io.containerd.grpc.v1.cri".containerd.runtimes.runc]
        runtime_type = "io.containerd.runc.v2"
```

### CRI-O配置
```toml
# /etc/crio/crio.conf
[crio]
  storage_driver = "overlay"
  storage_option = ["overlay.mountopt=nodev,metacopy=on"]

[crio.runtime]
  runtime = "/usr/bin/runc"
  conmon = "/usr/bin/conmon"
  conmon_cgroup = "pod"
  cgroup_manager = "systemd"

[crio.image]
  default_transport = "docker://"
  insecure_registries = ["registry.example.com:5000"]

[crio.network]
  plugin_dirs = ["/etc/cni/net.d/"]
```

## 🔧 镜像管理

### 拉取镜像
```bash
# Docker
docker pull nginx:latest

# containerd
ctr image pull docker.io/library/nginx:latest

# CRI-O
crictl pull nginx:latest
```

### 列出镜像
```bash
# Docker
docker images

# containerd
ctr image ls

# CRI-O
crictl images
```

### 删除镜像
```bash
# Docker
docker rmi nginx:latest

# containerd
ctr image rm docker.io/library/nginx:latest

# CRI-O
crictl rmi nginx:latest
```

## 🔧 容器管理

### 创建容器
```bash
# Docker
docker run -d --name my-container nginx:latest

# containerd
ctr run -d docker.io/library/nginx:latest my-container

# CRI-O
crictl run nginx:latest my-container
```

### 查看容器
```bash
# Docker
docker ps

# containerd
ctr container ls

# CRI-O
crictl ps
```

### 停止容器
```bash
# Docker
docker stop my-container

# containerd
ctr task kill my-container SIGTERM

# CRI-O
crictl stop my-container
```
